# ConnecThaLast

한글 · 영어 끝말잇기 웹 게임. 봇 대전, 보스전, 최대 30명 멀티플레이, 랭킹, 43만 단어 사전을 제공합니다.

- 플레이: https://connecthalast.vercel.app
- 현재 버전: **v3.2.2**

## 주요 기능

### 게임 모드

| 모드 | 설명 |
|---|---|
| 봇 대전 | 7단계 봇(초보봇 → 중수봇 → 고수봇 → 좀고수봇 → 초고수봇 → 신봇 → 롱봇)과 1대1 대결. 라운드 수 선택 가능 |
| 보스전: 사전의 재앙 | Lv.10 이상 입장. 보스가 낸 단어 3개를 6초 안에 모두 끝말잇기로 반격해 보스 체력 10칸을 깎으면 승리 (+750 EXP). 하트 5개를 잃거나 6분 55초가 지나면 패배 |
| 멀티플레이 | 방 만들기 / 방 코드 참가 / 공개 방 목록. 2~30명, 라운드 설정, 한국어·영어 선택, 상대 타이핑 실시간 표시. 3인 이상은 등수제 + 통합 랭킹 보드 |
| 영어 끝말잇기 | 37만 영단어 DB 기반 English Word Chain (봇 대전 · 멀티 모두 지원) |

### 게임 옵션 (한국어)

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 어인정 | ON | 게임/애니/노래 제목 등 비표준 단어 허용 |
| 자유두음 | ON | ㄴ/ㄹ/ㅇ 초성 자유 호환 (예: 륨 → 륨/늄/윰) |
| 매너 | OFF | 한방단어(이을 수 없는 글자로 끝나는 단어) 금지 |
| ~다 금지 | OFF | "다"로 끝나는 단어 금지 |

### 점수 · 경험치

- 단어 성공 시 기본 +20점, 2글자 초과분 1글자당 +5점
- 희귀도 보너스: 한국어 어인정 전용 단어 +15, 영어 6자 이상 +10 / 8자 이상 +25
- 실패 시 -25점 (0점 미만으로는 내려가지 않음). 최종 승자는 누적 점수가 높은 쪽
- 승리 · 긴 단어(5글자부터 +1씩) · 한방 마무리(+10) · 멀티 등수에 따라 EXP 지급
- 레벨업 필요 EXP = 100 + (레벨 − 1) × 5, 레벨 구간별 배지 (1~9 / 10~24 / 25~49 / 50~99 / 100+)

### 그 외

- **랭킹**: 레벨 · 전적 · 최근 접속 시간
- **단어 사전**: 표준 311,239개 + 어인정 124,601개 = 435,840개. 검색, 시작/끝 글자 · 글자수 필터, 한방 단어만 보기, 한방 루트 트리, 단어 클릭 시 뜻 · 품사 표시
- **소셜**: 온라인 플레이어, 친구 요청/목록, 1:1 채팅 (읽음 표시 · 실시간 타이핑 표시 · 안 읽은 메시지 배지)
- **공지사항**: 사이드바에서 확인, 안 읽은 공지 NEW 배지 (관리자만 작성/삭제)
- **문의 / 버그제보**
- **설정**: BGM · 효과음 볼륨, UI 언어 (한국어 / English)
- **BGM / 효과음**: 타이머에 따라 빨라지는 리듬 효과음, 단어 애니메이션 중 BGM 자동 음소거
- **테스트 서버**: DEV / Admin 전용 별도 프로필
- **입력**: 단어 입력창과 채팅창 모두 Enter 한 번으로 바로 전송 (한글 조합 중에도 동작)

## 기술 스택

- 프론트엔드: Vanilla HTML / CSS / JavaScript (프레임워크 · 빌드 도구 없음)
- 백엔드: Firebase Realtime Database (계정, 프로필, 방, 채팅, 공지, 랭킹)
- 호스팅: Vercel (정적 파일 + `/api/dict` 서버리스 함수)
- 사전 뜻 조회: 국립국어원 표준국어대사전 → 우리말샘 → `customDefs.js` 순서로 조회, 결과는 localStorage에 30일 캐시

### 환경변수

`api/dict.js`는 국립국어원 Open API 키를 환경변수로만 읽습니다. 코드에 키를 넣지 마세요.

| 이름 | 용도 | 발급 |
|---|---|---|
| `STDICT_KEY` | 표준국어대사전 API | https://stdict.korean.go.kr/openapi/openApiInfo.do |
| `URIMAL_KEY` | 우리말샘 API | https://opendict.korean.go.kr/service/openApiInfo |

Vercel 프로젝트 Settings → Environment Variables에 등록하면 됩니다. 로컬에서 `vercel dev`로 돌릴 때는 `.env.example`을 `.env.local`로 복사해 값을 채우세요 (`.env.local`은 git에서 제외됨). 키가 없으면 `/api/dict`가 500을 돌려주고 클라이언트는 `customDefs.js`로만 폴백합니다.

## 로컬 실행

정적 파일이므로 아무 HTTP 서버로 열면 됩니다.

```bash
python3 -m http.server 5555
```

그 다음 http://localhost:5555 접속. `/api/dict` 뜻 조회는 Vercel 함수라 로컬 정적 서버에서는 동작하지 않습니다 (`customDefs.js`에 정의된 단어만 뜻이 표시됨). 전체 동작은 `vercel dev`로 확인하세요.

## 버전 · 공지 규칙

버전은 `vX.Y.Z` 형식이며 변경 규모에 따라 올리는 자리가 다릅니다.

| 종류 | 올리는 자리 | 예시 | 내용 |
|---|---|---|---|
| 패치 | Z | v3.2.1 → v3.2.2 | 버그 수정, 작은 기능 개선, 단어 추가 |
| 업데이트 | Y | v3.2.x → v3.3.0 | 새로운 기능 추가 |
| 대규모 업데이트 | X | v3.x.x → v4.0.0 | 거의 새로운 개편 (신규 게임 종류, 시스템 전면 개편 등) |

버전을 올릴 때는 `index.html`의 `?v=` 캐시 쿼리(14곳), 버전 라벨(2곳), 점검 화면 문구(1곳)를 함께 갱신합니다. 공지는 게임 내 공지사항에 아래 형식으로 올립니다.

```
v3.2.2 패치
- 변경 내용
감사합니다
```
